# 💰 Finance Manager App v3

A powerful and intuitive personal finance tracking application built with **Flutter**. This app helps users manage their daily expenses, track budgets, and visualize their spending habits with ease.

---

## 🚀 Features

- **Expense Tracking:** Add, edit, and delete daily expenses with categories.
- **Budget Goal Setting:** Set monthly or weekly financial goals to save more.
- **Data Visualization:** Beautiful charts and graphs to analyze spending patterns (Analysis Screen).
- **Multi-language Support:** Support for English and Hindi (L10n).
- **Themes:** Custom UI themes (Dark/Light mode support).
- **Notifications:** Reminders to log daily expenses and bill alerts.
- **Profile Management:** Customized user profile with settings.

---

## 🛠️ Tech Stack

- **Framework:** [Flutter](https://flutter.dev/)
- **Language:** [Dart](https://dart.dev/)
- **State Management:** Provider (Settings & Themes)
- **Local Storage:** SQLite / SharedPreferences (depending on your implementation)
- **Assets:** Lottie Animations, Custom Icons, and Google Fonts.

## 📦 How to Install & Run

Follow these steps to run the project locally:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Ajeet2611/finance_Manager_Application.git](https://github.com/Ajeet2611/finance_Manager_Application.git)
2. Navigate to the project folder:
   
   cd finance_vanager_app_v3
3. Install dependencies:
   flutter pub get

4.  Run the app:
   flutter run
